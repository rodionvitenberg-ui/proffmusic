Правило: новый код витрины живёт в `web/` (Nuxt + Vue 3). Папка `vanmorrison/` — донор вёрстки. Папки `frontend/` больше нет.

## Словарь на старт

**Vue 3.** UI из компонентов. В отличие от React здесь реактивность в самом объекте данных (`ref` / `reactive`), а не в «перерисуй дерево после setState». Шаблон в `.vue` — это HTML с директивами (`v-if`, `v-for`, `v-model`), не JSX.

**SFC (Single File Component).** Один файл = шаблон + скрипт + стили. `<script setup>` — короткий синтаксис Composition API: то, что объявил, сразу видно шаблону.

**Pinia.** Глобальный стейт Vue (корзина, сессия, плеер). Аналог Zustand у нас в Next. Один store — одна тема, без «бога-объекта».

**Nuxt 3.** Vue плюс договорённости, которые в Next уже были: папка `pages/` становится роутером, можно рендерить на сервере, есть модуль i18n. Мы берём Nuxt не «потому что модно», а потому что магазину нужны `/ru` и `/en` и нормальные мета-теги на about/license.

**Кожа Van Morrison.** Один большой BEM-CSS (Oswald, Inria Serif, почти чёрный фон). Классы не переименовываем: так проще сверяться с макетом. Тексты VAN MORRISON → PROFFMUSIC.

## 2026-08-16 — каркас Nuxt в `web/`

**Зачем:** витрина должна жить на Vue целиком. Next-черновик шапки оставляем как есть и больше не развиваем.

**Что сделали:**
- `nuxi init web` (шаблон minimal, Nuxt 4).
- Модули: Pinia, `@nuxtjs/i18n`, плюс GSAP.
- Кожа: `web/assets/css/vm.css` + шрифты Oswald/Inria, футерные фото, hero-видео.
- Хром: `SiteHeader`, `SiteFooter`, раскладка `default`.
- Страницы-заглушки: `/music` `/collections` `/about` `/license` `/contacts` `/login` `/cart`.
- Главная: splash + hero PROFFMUSIC + веер (данные с Django, если он поднят).

**Урок фреймворка.** В Nuxt файл `app/pages/about.vue` сам становится маршрутом `/about`. Модуль i18n с `strategy: 'prefix'` делает из него `/ru/about` и `/en/about` — тот же приём, что `app/[locale]/` в Next, только без ручного сегмента. Компоненты из `app/components/` подхватываются без import: `SiteHeader` в лейауте — это автоимпорт. `useI18n()` / `useLocalePath()` — composable: функция, которая в setup даёт перевод и «правильный» путь с локалью.

**Проверка:** `cd web && npm run dev -- --port 3002`, открыть `http://localhost:3002/ru`.

**Заметка по i18n:** символ `@` в строках vue-i18n — это «linked message». Писать `shop@mail` нельзя, парсер падает. Либо `shop{'@'}mail`, либо обход вроде `(at)`.

## 2026-08-16 — каталог, плеер, корзина

**Зачем:** без `/music`, карточки трека и корзины кожа — только витрина-обложка. Магазин начинается здесь.

**Что сделали:**
- Pinia-сторы `cart` и `player` (`app/stores/`). Корзина пишет в `localStorage` ключ `pm-cart`.
- `/ru/music` — фильтры (категория + теги) через query string, сетка карточек, «Ещё».
- `/collections`, `/collections/[slug]`, `/tracks/[slug]`.
- Нижний `PlayerBar`: play/pause/next/prev, превью с бэка.
- `/cart`, `/checkout` (POST на существующий Django `/api/orders/checkout/`), `/success`, черновик `/login` и `/profile`.

**Урок.** Pinia-стор — это не React Context. `defineStore` даёт один общий объект: любой компонент вызывает `useCartStore()` и видит те же `items`. Query в Nuxt — `route.query`; фильтры мы кладём в URL (`?category__slug=`), а не в скрытый стейт, чтобы ссылку можно было скопировать. `useAsyncData` на странице трека — серверный fetch: Nuxt сходит в Django до отдачи HTML, потом гидратирует. Если бэкенд лежит, страница всё равно рисуется, просто «не найдено».

**Проверка:** `http://localhost:3002/ru/music`. Пока Django не запущен, пустой каталог — норма. Подними `backend` и обнови — появятся карточки.

## 2026-08-16 — профиль, заказы, Next вырезан

**Зачем:** кабинет и история покупок — последние живые экраны старого Next. Пока они в `web/`, Next можно удалить.

**Что сделали:**
- Pinia `auth`: JWT в `localStorage` (`accessToken`), `login` / `register` / `fetchMe` / `uploadAvatar`.
- `/login`, `/register`, `/profile` (ssr:false). Профиль тянет `GET /api/users/orders/` и грузит аватар на `POST /api/users/upload_avatar/`.
- Checkout шлёт `Authorization` и подставляет email из сессии — заказ привяжется к юзеру и всплывёт в истории.
- Папка `frontend/` удалена. Прод: `web/` + PM2 `proffmusic-web`. Локально CORS/CSRF ждут `:3002`.

**Урок.** JWT на клиенте — не cookie-сессия. Nuxt на сервере токена не видит, поэтому профиль без SSR: сначала гидратация из `localStorage`, потом `$fetch` с `Bearer`. Djoser: логин по email, при создании юзера `username` = email.

**Проверка:** `http://localhost:3002/ru/login` → профиль. Заказы пустые, пока нет оплаченного `user=` на заказе.
